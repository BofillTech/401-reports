How owner contact works: Rhode Island publishes parcel boundaries, size, and land type for all 38 towns in one live statewide layer — but it does not publish owner names or mailing addresses (those live in each town's assessor). So this search finds and filters the land; the owner name, mailing address, and phone are appended by the skip-trace step for the parcels you choose. Export the rows you want, then run them through skip-trace.
Live query to Rhode Island's statewide tax-parcel service (RIGIS / RIDEM), updated by the 39 municipalities — results reflect the state database in real time. Vacant-land owners are cold prospects: 401 reaches them by direct mail only (never AI calls), per TCPA. Prepared by Bofill Technologies.
